# Start here — direct GitHub main import

1. Extract the whole archive.
2. Run `python scripts/check_site.py` (or `python3` on macOS/Linux).
3. Run the matching `UPLOAD_TO_GITHUB_MAIN_WINDOWS.ps1` or `UPLOAD_TO_GITHUB_MAIN_MAC_LINUX.sh` uploader, which **pushes to `main` directly**.
4. Verify the website source and automated checks in your GitHub repository.
5. Select either WordPress or standalone deployment, complete the real-world content/legal/form sign-offs, and only then configure the public site.

**60 pages are included.** No staging branch or staging deployment is required. All source code can live on main while legal and website approval gates remain in effect.

See `README.md`, `IMPORT_TO_GITHUB.md`, and `DEPLOYMENT.md`.
