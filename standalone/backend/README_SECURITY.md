# Enquiry operations

The server stores enquiries in SQLite under `SEO_LEADS_DATA_DIR`, outside the public site directory. Session validation, same-origin checks, a honeypot, request limits and a per-address submission limit are included. SQLite connections are closed after each transaction.

Run behind HTTPS with secure cookies, a trusted reverse proxy, the expected production hostname and real mail credentials. Production startup requires an approved release marker. The Docker build uses only `release/site/`, generated by the release builder.

Mail failures leave the enquiry saved. Use `serve.py --retry-notifications` from a monitored private host job. Use `--backup-db` for consistent private backups and test restoration before launch. These commands do not expose public export or administration endpoints.

The bundled server is a reference implementation. Validate capacity, patching, proxy configuration, persistent storage, backups, spam controls and actual inbox delivery on the chosen host. Do not expose the backend, environment files, SQLite database or exports as static files.
