SEO KPIs: Completed Work, Search Performance and Enquiries

Record a baseline you can repeat

Save the reporting period, data sources and filters before work begins. Note whether branded searches are included, which locations are tracked and how enquiries are counted. Without these details, comparisons can reflect a change in measurement rather than a change in performance.

Use separate measures for work and outcomes

For delivery, report tasks completed, changes published and work still awaiting approval. For search, report relevant query positions, clicks and landing pages. For the business, count enquiries or sales only where tracking supports them, and distinguish useful contacts from spam or wrong-service requests.

Explain the change

When a number moves, identify the affected service or page and record relevant site or tracking changes. State what is known and what still needs investigation. The next action might be fixing a form, improving a page or checking a lost query. A KPI should help choose that action, not serve as a guaranteed outcome.
